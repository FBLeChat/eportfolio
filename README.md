# E-Portfolio Ingénieur - Félix Bellais

Ce dépôt héberge le code source de mon e-portfolio académique bilingue (Anglais / Français), développé dans le cadre de ma formation d'ingénieur en électronique à l'ENSEEIHT (INP Toulouse). 

Ce projet web interactif centralise :
- **Engineering Courses :** Mes travaux scientifiques (TIPE, projets N7).
- **International Mobility :** Mon parcours atypique et mes objectifs de mobilité.
- **Sustainability & Civic Engagement :** Mon implication associative (Photo7, Can7) et mon projet citoyen.
- **Sports & Activities :** Ma pratique sportive (Kitefoil, Beach Volley) et mes loisirs numériques (Blender 3D).
- **Career Development :** Mon projet professionnel dans les systèmes embarqués critiques (défense et aéronautique).

## Détails Techniques
- **Architecture bilingue :** Bascule instantanée FR/EN gérée nativement via JavaScript (localStorage) et classes CSS, évitant toute duplication de pages HTML.
- **Design :** Template "Forty" par [HTML5 UP](https://html5up.net/) (Creative Commons Attribution 3.0 License).
